i.

The model

+

SketchUp native file, plus FBX, OBJ, DAE and 3DS exports. Objects are separate named groups, never welded, and the file carries no protection of any kind.

ii.

The light

+

A Lumion scene with materials, cameras and lighting saved. The flagship houses ship up to four setups on one camera path: dawn, day, overcast or sunset, and night.

iii.

The drawings

+

Exterior packages include a coordinated 2D set in SketchUp LayOut and PDF: site plan, floor plans, elevations and sections, up to ten sheets.

iv.

The post-production

+

Every final render ships as a layered PSD with its material ID pass; the exterior scenes add lighting and sky alpha passes, so you can see how each image was finished.
